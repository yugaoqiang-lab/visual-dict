# 科莱德图解词典 · 使用说明

基于 DK《Chinese-English Bilingual Visual Dictionary》制作的**离线**中英图解词典 App：保留原书插画，每个单词带美式音标、可点击发音，并支持单词搜索、生词本收藏、点词跳到对应图典页。

全部功能**无需联网**，数据已内置在包内。

---

## 一、四件套怎么选

| 文件 | 平台 | 适用场景 | 体积 |
|---|---|---|---|
| **VisualDict-release.apk** | Android 手机/平板 | 装到安卓设备当 App 用（推荐） | ~51 MB |
| **VisualDict-SingleFile.zip** | Windows | 单文件 exe，解压即得 `VisualDict.exe`，最便携 | ~77 MB |
| **VisualDict-app.zip** | Windows | 文件夹版 exe，启动更快（免运行时解压） | ~77 MB |
| **dict-mobile.zip** | 手机浏览器 | 安卓/iOS 用文件管理器解压后开 `home.html`，轻量图秒开 | ~48 MB |

> 四件套功能完全一致（看图 + 搜索 + 收藏 + 跳页），只是载体不同。

## 二、各平台安装使用

### 1. Android（VisualDict-release.apk）
1. 把 `VisualDict-release.apk` 传到手机（微信/网盘/数据线均可）。
2. 手机「设置 → 安全/隐私」开启**「未知来源安装」**（不同品牌叫法略异）。
3. 点 apk 文件安装，桌面出现「图解词典」图标。
4. 打开即用。**点单词发音**依赖系统 English(US) 语音包：设置里搜「语音」→ 确认已安装并下载「English (United States)」TTS 语音（无网络也能用，但需本机有该语音数据）。

### 2. Windows 桌面（exe）
- **单文件版**：解压 `VisualDict-SingleFile.zip` → 双击 `VisualDict.exe`。
- **文件夹版**：解压 `VisualDict-app.zip` → 进 `VisualDict/` 文件夹 → 双击 `VisualDict.exe`（启动更快）。
- 需要系统 **WebView2 Runtime**（Win10/11 大多预装；若报缺组件，去微软官网装一下即可）。
- 点单词发音依赖系统的 en-US 语音包。

### 3. 手机浏览器（dict-mobile.zip）
1. 解压 `dict-mobile.zip` 到手机某文件夹（得到 `home.html` + `search.html` + `index2.html` + `words.js` + `pages_mob/`）。
2. 用手机浏览器（Chrome/Safari）打开该文件夹里的 **`home.html`**。
3. 建议「添加到主屏幕」当伪 App。点发音依赖手机 en-US TTS 语音包。

## 三、功能一览

- 📖 **图解词典**：原书 313 页插画，单词透明可点击层；右侧红/蓝色 IPA 标签（红=词典注音，蓝虚线≈=规则推算近似音标）；上一页/下一页/跳页/方向键；音标显隐开关；页内搜索高亮。
- 🔍 **单词搜索**：实时按英文/中文过滤（高亮匹配），显示音标（近似蓝+≈）、中文；🔊 朗读；📖 一键跳到该词在图典里的原书页。
- ★ **生词本（收藏）**：两种收藏方式——① 看图时点顶部「⭐ 收藏模式」，直接点单词加入/移出生词本（已收藏词显示**琥珀色下划线**）；② 搜索结果点 ☆。收藏存浏览器/App 本地（`localStorage`），**刷新、重开都不丢**；首页「★ 我的生词本」或图典页「📚 生词本」按钮直达收藏列表随时复习。
- ⚙️ **生词本管理（导出/导入/清空）**：搜索页点「⚙️ 管理」打开面板——① **导出**：生成含全部收藏词的 JSON（可「复制」到剪贴板，或「下载生词本.json」文件）；② **导入**：粘贴别人发来的 JSON 文本（或选 `.json` 文件，桌面端）即可合并进自己的生词本；③ **清空**：两次确认后清除全部收藏。这是**换设备/换端迁移**生词本的标准做法（安卓 WebView 受文件权限限制，主路径用「复制 JSON 文本 → 粘贴导入」最稳）。
- 🎯 **听写测验（听音 / 看中文 双向）**：在生词本页点「🎯 听写测验」，可一键切换出题方向——**🔊 听音**：播放英文发音、手写拼写；**📖 看中文**：显示中文释义、写出对应英文单词。即时判分并显示答案与音标/中文；回车提交，可「显示答案 / 下一个」。每轮结束给出**本轮得分（对x/错y）与拼错的词清单**，可「🔁 重练错词」反复练到全对。纯本地、不联网。
- 📝 **选择题测验（英→中 / 中→英 双向）**：在生词本页点「📝 选择题」，可一键切换方向——**英→中**：看英文 + 🔊 发音，从 4 个中文释义里点选正确项（干扰项自动从词库抽取）；**中→英**：看中文释义，从 4 个英文单词里点选正确项（干扰项自动从你的生词本抽取）。即时判分高亮对错、可「下一个」。**手机点选零打字**，纯前端不联网。两种方向都按「到期优先、薄弱优先」排序。
- 📊 **学习统计 + 间隔重复（智能复习）**：每次测验（听写 / 选择题）自动记录每个词的「对 / 错」并排**复习计划**（答对→间隔翻倍、最长 30 天后再出现；答错→立刻回来重练）。搜索页点「📊 统计」看收藏 / 已测验 / 已掌握 / **待复习(今日到期)** / 未测验，并列出最薄弱词与各自「下次复习」时间；两种测验都按「到期优先、薄弱优先」排序。点「🔁 智能复习」只练**今天到期的词**（无到期词则退而练最薄弱），高效巩固。生词本导出 JSON 时一并带走学习记录，换设备可恢复进度。
- 📕 **错题本 + 错词专项练习**：点「📕 错题本」看所有**测验中曾经答错过**的词（按错误次数降序排列，每行显示 对x/错y · 下次复习时间），一眼看清自己的盲点；一键「🔁 只练错词」把这些词拉进选择题专项练习（**英→中 / 中→英** 皆可，复用现有抽题/判分/间隔重复逻辑），针对性消灭易错词。与统计、智能复习共用同一份学习记录。
- 📊 **测验结束汇总（每轮复盘）**：每轮选择题（含「📝 选择题 / 🔁 智能复习 / 📕 错题本只练错词」）结束时，不再只显示"🎉 本轮完成"，而是给出**本轮得分（对x / 错y）**并列出**答错的词及正确答案**；一键「🔁 重练错词」把这些错词立刻拉起新一轮专项练习，可反复练到全对。与错题本、间隔重复共用同一份学习记录。
- 🔥 **每日打卡（连续学习 Streak）**：顶栏「🔥 N 天」徽章记录连续学习天数——每完成一轮测验（听写 / 选择题，含智能复习、错题本专项）当天自动累计，连续每天学习累积连胜、中途断一天则从 1 重新计；统计面板「连续打卡」卡片显示当前连胜与历史最佳。打卡数据存 `localStorage['vd_streak']`，刷新重开不丢，纯本地激励、不联网。
- ⏱ **限时挑战（每题倒计时）**：选择题 / 听写测验面板都加了「⏱ 限时」开关（状态存 `localStorage['vd_timed']`，跨重启记住）；开启后每题带实时倒计时（选择题 10 秒、听写 12 秒，顶栏显示剩余秒数），超时自动揭示正确答案、记一次错误并自动跳下一题，逼你练出"又快又准"。计时器在答题 / 退出 / 本轮结束 / 手动显示答案时自动清理无残留；重练错词同样限时。手机零打字的场景（选择题）练反应尤其合适，纯本地、不联网。
- 📚 **全词库练习（不收藏也能系统过词）**：顶栏新增「📚 全词库」开关（状态存 `localStorage['vd_studyall']`，跨重启记住）；开启后「🎯 听写测验 / 📝 选择题」不再只抽你的生词本，而是从**全书 5677 词**随机抽取（选择题只取带中文释义的词），适合还没收藏、想从头系统刷词或发现该背词的场景；关闭则回到只练生词本（默认）。「🔁 智能复习 / 📕 错题本」仍基于你的生词本（那本是你的学习资产），不受影响。开启时面板提示也同步显示「全书随机抽词」。纯本地、不联网。
- 🏅 **成就徽章系统（里程碑自动点亮）**：顶栏新增「🏅 成就 N/10」徽章（点它即开「📊 统计」面板，底部新增「🏅 学习成就」区）；学习过程中的 10 个里程碑会**自动点亮**成徽章——🎯 首轮完成（完成第一轮测验）、🔥 三日打卡 / ⚡ 一周打卡（连续打卡达 3 / 7 天）、🌱 初窥门径 / 🌳 渐入佳境（掌握 10 / 50 个词，r≥2 且 w=0）、💎 完美一轮（单轮测验全对）、⏱ 限时高手（限时模式累计答对 10 题）、📚 博览全书（完成一次全词库练习）、🎓 小试身手 / 🏆 勤学不辍（累计完成 10 / 50 轮测验）。解锁瞬间弹 toast 提示，已解锁徽章高亮、未解锁置灰显示达成条件。成就数据存 `localStorage['vd_ach']`（解锁记录 + 限时累计 `timedOk`），纯前端、复用现有 streak/stats 数据、零风险，刷新重开不丢。
- 📈 **学习趋势曲线（测验历史）**：「📊 统计」面板底部新增「📈 学习趋势」区——每完成一轮测验（听写 / 选择题，含智能复习、错题本专项、重练错词）自动记录一条 `{时间, 题型, 方向, 对, 错}` 到 `localStorage['vd_history']`（最多保留最近 60 轮），并用**内联 SVG 柱状图**画出最近 24 轮的正确率（全对绿色、其余蓝色，悬停看「题型·对x/y」）；上方一行汇总「最近 N 轮 · 平均正确率 X% · 全对 Y 轮 · 累计 Z 轮」，一眼看清自己的进步曲线。完全离线、不联网，与成就里的「小试身手 / 勤学不辍」联动。
- 📂 **生词本分组（收藏集 Study Sets）**：顶栏新增「📂 收藏集」入口——把庞大的生词本拆成多个主题集（如「食物 / 工作 / 易错词」），针对性练习。在收藏集面板可「➕ 新建分组」、给每个集一键「📝 选择题 / 🎯 听写」专项测验、或「👁 查看」该集单词；删除分组不丢词（词自动回「未分组」）。收藏列表里每个词多了个「▸」按钮，点它弹层选择加入哪个集 / 新建并加入 / 移出（未分组）；当前所在集高亮。筛选查看时列表顶部有「✕ 清除筛选」。分组数据存 `localStorage['vd_sets']`（集名数组）+ `vd_setmap`（词→集Id），纯前端、零风险、刷新重开不丢，并随生词本导出 JSON 之外的独立存储（换端可手动迁移）。
- 📋 **全词库总表（单词清单 · 整本浏览）**：顶栏新增「📋 词表」入口——**不用搜也能整本翻看全部 5677 词**：每页 60 条、底部「← 上一页 / 下一页 →」（显示「第 X / Y 页」），每行保留 🔊 朗读 / 📖 看图解 / ☆ 收藏 / ▸ 入集，可在词表页直接收藏或归到收藏集；顶部搜索框输入关键词即在全词库内实时过滤并重新分页。这是对「全部」(纯搜索)和「★ 收藏」(仅生词)之外的第三种浏览方式，专门补齐"整本单词清单"需求。纯前端、零风险，与收藏/收藏集完全联动。
- 📅 **测验历史·近 7 天周视图（按日聚合）**：「📊 统计」面板的「📈 学习趋势」区新增「📅 近 7 天」子块——把 `localStorage['vd_history']` 按**本地日期**聚合，用内联 SVG 柱状图画出**最近 7 天每天完成的测验轮数**（全对天绿色、有错天蓝色、零天浅灰），柱下标注「月/日」，悬停每根柱显示「日期（周X）· N 轮 · 正确率 X%」；上方一行汇总「近 7 天共 N 轮 · 平均正确率 X% · 单日最多 Y 轮」。与上方「最近 24 轮」单轮曲线互补：一个看"每次表现"、一个看"每天坚持"，一眼知道自己这周有没有掉队。纯前端、复用现有历史数据、零风险、离线可跑。
- 💾 **全量学习进度备份（跨设备迁移）**：「⚙️ 管理」面板从"只备份生词本"升级为**整份学习进度全量备份/恢复**——导出(`buildBackup()`)的 JSON 现含 `words`(收藏)+ `stats`(SRS 统计)+ `streak`(打卡)+ `ach`(成就)+ `history`(测验历史)+ `sets`/`setmap`(收藏集)，文件名 `学习进度备份.json`；导入(`doImport`)**合并恢复**：收藏取并集、SRS 统计取缺失键、打卡取 count/best 较大值、成就取并集、历史追加并截断至最近 60 条、收藏集按 id 补缺失、setmap 取缺失键，导入后同步刷新打卡/成就徽章/收藏集/列表并提示「+N 收藏 · 历史 M 条 · 成就 K 项 · 收藏集 J 个」。换安卓/Win/手机浏览器任意一端，导一份 JSON 即可把全部学习痕迹带走或恢复，彻底解决离线 App 的跨端痛点。纯前端、零风险、保留旧版 `words` 导入兼容。
- 共 **5677** 个唯一单词、覆盖 **313** 页，约 **95.5%** 带美式音标（剩余为解剖学拉丁词，可点击 TTS 发音）。

## 四、技术说明（给维护者）

- **数据源**：`cards-data/word_ipa_list.csv`（英文/IPA/近似?/出现页）+ `dict.json`（中文）；`gen_words.py` 生成 `words.js`（格式 `[[英文,IPA,近似0/1,中文,出现页],...]`）。
- **图典页**：`build_interactive.py` 由 PDF 渲染 `pages/`（全分辨率）与 `pages_mob/`（压缩轻量版，手机用）。
- **安卓**：`android-app/` 为原生工程（包名 `com.klyde.visualdict`）。`MainActivity` 起一个本地 `ServerSocket`（127.0.0.1:8765）以 HTTP 提供 `assets/`，既给 WebView 安全上下文让 `speechSynthesis` 可用，又完全离线。
  - 重编：`android-app/build-apk.bat`（需本机 Android SDK/JDK/Gradle，离线）。
  - **发布密钥密码：`Klyde@2026`**（store/key 同），丢了无法给已装用户推送更新，务必保管。
- **Windows exe**：`app.py`（pywebview 加载 `home.html`）+ PyInstaller 打包。`build.bat` 一键出文件夹版；单文件版把 `build.bat` 里 `--onefile` 那行注释切换即可。
- **收藏存储**：所有端统一用 `localStorage['vd_favs']`（单词英文名数组）。安卓因同源（127.0.0.1）跨页共享；Windows/手机浏览器依具体内核同源策略，收藏在同一 App/站点内有效。
